Tests, Nodes and Evidence

What a PASS actually means.

A test node is a checkpoint in a validation process. It asks a limited question about input, transition, output or provenance. It is not necessarily a physical node, a tentacle or a computer server.

1. CubeAre the six named commitments present?
2. SnapshotIs the submitted state exactly 1536 bits? Is its derivation known?
3. BoundaryDoes the model avoid assuming continuity?
4. SphereCan post-gap relationships be checked against recorded origin?
5. ReceiptDoes a record identify what was observed, without claiming native execution?

Read the results

PASS means a particular executable assertion held. FAIL means it did not. UNKNOWN means evidence or implementation is missing. UNVERIFIED receipts record simulation content consistency, not authenticated firing.

What the automated tests do

JavaScript and Python regression tests exercise snapshot validation, immutability, geometry-hash binding, replay rejection and closed-gate receipts. GitHub Actions is an automated runner for these tests, not part of the physical or geometric model.
