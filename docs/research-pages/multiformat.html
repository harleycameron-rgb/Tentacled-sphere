Scope and privacy

No network upload or persistent storage is implemented. File bytes are not opened, decoded, hashed or retained. File metadata can be identifying; exports are explicitly initiated by you. This page is not a media-processing engine.

Future adapters may derive image topology, paired video/audio channels, silence-gap comparisons, sensor traces, QOB projections and 512-layer fabric receipts. Those functions are not implemented here; they require modality-specific validation and privacy tests.
