# MDL Human Frame / Glass Viewport

Status: Draft PR implementation and interpretation constraint, not a certified security boundary.

## Geometric / epistemic constraint
The glass is a viewport through which a human observes a bounded projection of a separate read-only lineage. Sentinel anchors the provenance endpoint; varying window visibility, zoom, filter, expertise, expectation or instruments do not modify that lineage. A human's recognitions, experience or prior models cannot be automatically promoted into true invariant claims. Observations must remain falsifiable; visible resemblance is not equivalence.

## Structural separations
- **Source**: anchored Sentinel lineage; no reverse edge from observer.
- **Glass**: noninteractive projected view; no observer command handler on the glass SVG.
- **Separate browser simulation**: legacy local controls still exist outside the pane and may alter simulated snapshots; not native core authority.
- **Parallel sandbox**: legitimate observation-based modeling and candidate/residue comparison downstream of DaemonGate. The current web branch has app-local feeds but has NOT proved a connected DaemonGate pulse adapter.
- **Native Zero**: core trigger reservation remains disconnected and the native gate remains CLOSED.

## Implementation record
The shared `web/app-template.html` now explicitly frames the SVG in `.human-observation-glass`. `web/style.css` makes the graphical surface noninteractive and gives the glazing a visible optical edge. Simulation controls are outside the glass and described as separate. The nine generated pages were regenerated from the template. Incoming feeds remain available for local preview but no longer auto-ignite shared simulation revisions.

## Limits
CSS pointer-event exclusion and semantic text are UI constraints, not authorization enforcement, evidence of security, or proof that raw observer interpretation cannot bias an upstream model. Independent service isolation, trusted provenance, and tests of denied write paths would be required before claiming such a guarantee. Nothing in this change grants a native firing path or asserts true invariance.
