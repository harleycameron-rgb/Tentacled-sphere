## Adapter design, not yet implemented
Each format adapter should declare: modality, acquisition conditions, ephemeral input lifecycle, transformation version, geometry schema, validation status, error conditions, retained metadata and permitted export formats. Video and audio channels from one event share an event identity but maintain separate transformations and proofs. Unknown and missing measurements must not be zero-filled. Hash consistency does not establish physical invariance or execution. QOB projections and 512-layer fabric need independent acceptance tests.

## Security and release
No engine connection, native firing, production DNS change or private raw-data upload. Preview instrument pages must not be described as verified SCANDOC native modules. Public preview release is separate from draft branch merge.
